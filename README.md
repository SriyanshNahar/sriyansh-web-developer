# Sriyansh Nahar — Portfolio

Graphic design and web development portfolio for Sriyansh Nahar. Built with Next.js, Tailwind CSS, and GSAP ScrollTrigger.

## Sections

- Hero — animated intro with a Three.js background
- About — bio and studio profile
- Experience — professional history
- Field Log — personal/lifestyle photos
- Visual Gallery — packaging and brand design work
- Dev Work — web development projects
- Skills — full skills breakdown
- Adaptive Agent — interactive terminal-style callout
- Contact — WhatsApp-connected contact form

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

Deployed on Netlify. Build command: `npm run build`.
